# Homebrew Tap for Brew Guide

咖啡冲煮指南 (Brew Guide) 的 Homebrew Cask 安装源。

## 安装

```bash
brew tap chuthree/brew-guide
brew install --cask brew-guide
```

## 更新

```bash
brew upgrade --cask brew-guide
```

## 卸载

```bash
brew uninstall --cask brew-guide
brew untap chuthree/brew-guide
```

## 关于

Brew Guide 是一款咖啡冲煮辅助工具，提供冲煮计时、咖啡豆管理和品鉴记录功能。

- 官网：https://coffee.chu3.top
